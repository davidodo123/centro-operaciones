Pasos:
1. Descarga con curl estos cinco archivos de datos a una carpeta del scratchpad (raw.githubusercontent.com funciona desde el shell):
   https://raw.githubusercontent.com/davidodo123/centro-operaciones/main/out/<id>.json para id = proyectos, proyectos_metricas, horas_dia, fases, tokens_dia.
   Comprueba que cada uno es un array JSON válido (por ejemplo con python3 -c "import json,sys; json.load(open(sys.argv[1]))" <archivo>). Si alguno falta o no es válido, no lo subas y dilo al final.
2. Para cada archivo válido:
   a. ArtifactData get collection "datasets", doc_id = el id → anota source.url (el id del blob viejo) y version.
   b. Artifact publish con url del dashboard, asset: true, file_path = el archivo descargado → url nueva.
   c. ArtifactData update collection "datasets", doc_id = el id, if_version = la version leída, data: {source: {kind: "file", url: <nueva>, name: "<id>.json"}, updated: {at: <hora ISO actual>, by: "Tarea programada (datos del PC de David)"}}.
   d. Si la update funcionó, borra el blob viejo: Artifact action "delete", url del dashboard, path = id del blob viejo (sin "/_blob/").
3. Si cambió algo respecto a la versión anterior (un proyecto nuevo o que ha salido, más commits, otro porcentaje), añade una fila al dataset "actividad" con el mismo proceso 2a-2d: lee su JSON actual (Artifact read con path = id de su blob), añade {id: "l<siguiente número>", fecha: <hoy YYYY-MM-DD>, proyecto: "Sistema", agente: "@kernel", accion: "Métricas: <Proyecto> X % / Y h, ..."
